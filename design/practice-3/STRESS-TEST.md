## Дополнительные проверки анимаций
Для основной и вторичной кнопок Chromium проверил фактический CSS-переход при наведении, масштаб при нажатии, клавиатурную рамку, блокировку и вращающийся индикатор при загрузке, восстановление кнопки после завершения. При эмуляции `prefers-reduced-motion: reduce` переходы, смещения и вращение отключены. Скриншоты 13 и 14 показывают состояния и запуск загрузки; движение проверяется в браузере, а не по статичному снимку.

## Воспроизведение проверок
`python verify.py` в этой папке при установленных Playwright и Chromium (`/usr/bin/chromium`). Скрипт встраивает те же локальные CSS и JS в HTML для рендеринга: в среде проверки прямые переходы по file:// и localhost запрещены политикой браузера. Для проверки состояний он подставляет соответствующий query string в JS и создаёт новый браузерный документ. Это не тест реального веб-сервера, сетевого запроса или интеграции ML.

## Что осталось
Подключить реальную модель и извлечение данных из файлов/ссылок, проверку содержимого файла, реальные этапы ожидания. Для очень больших списков в production нужна пагинация или виртуализация, сейчас тест проверяет рендер и отсутствие горизонтального переполнения, не нагрузочную производительность. Контраст/доступность проверены на уровне токенов и отдельных интерактивных сценариев, не полноценный аудит WCAG. Исходный прототип сохранён в practice-3.

## Обновление главной и сценария
Сохранён светло-серый фон. Четыре локальные сгенерированные фотографии (повар, строитель, разработчик, медработник) размещены в `assets/`. На широком экране при наведении или клавиатурном фокусе этап расширяется, остальные сужаются; высота не меняется. На узком экране текст виден сразу. Скриншот 17 — наведение. Фотографии не добавляют новых CSS-цветов.
Отдельное поле требований и дублирующий предпросмотр объединены в единственный блок описания выбранной вакансии. Пример резюме основан на первой странице предоставленного `resume-python-developer.pdf`, без шаблонных полей и служебной страницы. Ссылка на вакансию №139715357 сохранена, её содержание недоступно. Семь учебных пунктов для Python-разработчика не являются подтверждёнными требованиями этой вакансии; результат явно маркируется демонстрационным. Для реальной сверки вставь описание вакансии вместо примера. Заранее извлечённый текст может подставляться для точного исходного PDF по SHA-256 при наличии Web Crypto; эта ветвь не проверена в браузерной среде. Универсального PDF-парсера нет. Автотесты выполняют рендеринг с встраиванием CSS, JS и локальных изображений из-за блокировки file:// в тестовой среде.
