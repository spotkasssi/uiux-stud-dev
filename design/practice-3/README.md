# Практика 4 — минимальная дизайн-система «Сверка»

Выполнено на основе исходного HTML-прототипа из `../practice-3/` и брифа проекта. Требования лекции 4, слайды 54–58: до 15 цветов, 5–7 компонентов, экраны сценария, четыре состояния результата, стресс-тест и подсчёт «было/стало».

## Запуск
Открой `index.html` в браузере. Сборка и сервер не требуются. Нажми «Посмотреть пример» на главной или «Заполнить пример» в форме, затем «Сверить». Страница `components.html` содержит UI kit и ссылки на все демонстрационные состояния. Для запуска через локальный сервер из этой папки: `python -m http.server 8000`, затем `http://localhost:8000/`.

## Что сдаём
- `tokens.css` — 14 цветов, 8 отступов, 3 радиуса, 5 текстовых стилей.
- `DESIGN.md` — правила оформления и компоненты.
- `styles.css`, `index.html`, `app.js` — интерактивный пересобранный прототип.
- `components.html` — каталог шести компонентов и токенов.
- `screenshots/` — 17 скриншотов реального рендеринга Chromium.
- `verify.py`, `test-results.json` — воспроизводимые проверки и точные списки значений.
- `STRESS-TEST.md` — результаты, изменения и ограничения.
- `CHECKLIST.md` — проверка каждого пункта задания (слайды 54–58).

## Анимации
В `components.html` — матрица 2 × 6 состояний и две рабочие демонстрационные кнопки. Наведение приподнимает кнопку, нажатие уменьшает до 97%, фокус остаётся видимым, загрузка блокирует повторный запуск и показывает спиннер. При `prefers-reduced-motion: reduce` движение отключается. 46 автоматических проверок прошли.

## Ограничение
Это учебный UI-прототип, не готовый ML-сервис: проверка локальная по совпадению строк и отдельных слов. Выбор файла проверяет имя, размер и непустоту, TXT читается автоматически; исходный PDF-пример распознаётся по SHA-256 при доступности Web Crypto, остальные PDF/DOCX требуют ручного копирования текста; ссылка hh.ru не загружается. Ошибка модели и прогресс демонстрационные. Данные не отправляются на сервер. При перезагрузке введённый текст сбрасывается.

## Как проверить правки

Открой `index.html`: поля пустые, серые примеры не являются данными. Выбери TXT с резюме или введи текст, вставь описание в единый блок выбранной вакансии. При выборе PDF/DOCX проверяется расширение и размер; текст вставляется вручную. Неподдерживаемый файл нужно убрать или заменить. Нажми «Сверить»: индикатор справа снизу, затем результат и уведомление об успехе. Для ошибки открой `index.html?state=error`; кнопка «Повторить» запускает успешную повторную попытку. Для имитации сбоя после отправки используй `index.html?fail=1`. Скриншоты 15–16 — неправильный и принятый файл.

## Обновление главной и сценария
Сохранён светло-серый фон. Четыре локальные сгенерированные фотографии (повар, строитель, разработчик, медработник) размещены в `assets/`. На широком экране при наведении или клавиатурном фокусе этап расширяется, остальные сужаются; высота не меняется. На узком экране текст виден сразу. Скриншот 17 — наведение. Фотографии не добавляют новых CSS-цветов.
Отдельное поле требований и дублирующий предпросмотр объединены в единственный блок описания выбранной вакансии. Пример резюме основан на первой странице предоставленного `resume-python-developer.pdf`, без шаблонных полей и служебной страницы. Ссылка на вакансию №139715357 сохранена, её содержание недоступно. Семь учебных пунктов для Python-разработчика не являются подтверждёнными требованиями этой вакансии; результат явно маркируется демонстрационным. Для реальной сверки вставь описание вакансии вместо примера. Заранее извлечённый текст может подставляться для точного исходного PDF по SHA-256 при наличии Web Crypto; эта ветвь не проверена в браузерной среде. Универсального PDF-парсера нет. Автотесты выполняют рендеринг с встраиванием CSS, JS и локальных изображений из-за блокировки file:// в тестовой среде.

## Выравнивание формы
На широком экране обе колонки используют общие строки CSS subgrid: заголовки, зоны загрузки и ссылки, текстовые поля. Высота текстовых полей одинаковая при первом открытии; на узком экране колонки складываются вертикально. Размер lead увеличен до 20, заголовок первого экрана крупнее. Учебные подписи и ссылки на тестовые состояния убраны из публичного интерфейса; каталог компонентов и тестовые URL сохранены для сдачи. Ограничения текстового сопоставления и пометка непроверенного примера вакансии сохранены.
