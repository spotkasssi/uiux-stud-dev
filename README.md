# Сверка

Сервис для студентов и выпускников, которые ищут стажировку или первую работу на hh.ru. Студент даёт резюме и ссылку на вакансию. В ответ он получает не один балл, а список требований вакансии: у каждого требования статус («есть», «проверьте», «нет») и цитата из резюме, на которой этот статус основан. По пробелам сервис задаёт вопросы, чтобы найти настоящий опыт из учёбы и подработок, а не придумывать его.

> Название рабочее. Проект выполняется в рамках курса по проектированию ML-продуктов.

## Команда

| Участник | Роль | За что отвечает |
| --- | --- | --- |
| (имя) | ML-инженер | извлечение требований, сопоставление, оценка качества |
| (имя) | Fullstack-разработчик | backend, frontend, загрузка вакансии по ссылке |
| (имя) | UX/UI-дизайнер, исследователь | сценарии, макеты, опрос студентов |

## Ниша

Работа и HR: ИИ-анализаторы резюме для соискателей.

## Главная идея в одной строке

Конкуренты показывают одно число, которому нельзя верить (одно и то же резюме получает в разных сервисах от 21% до 80%). Мы показываем, на чём основан каждый вывод, и честно говорим, где модель не уверена.
